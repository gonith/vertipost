Vertipost

Application Windows pour publier une vidéo verticale sur YouTube Shorts, Instagram Reels et TikTok.

Vertipost est une application de bureau qui tourne sur l'ordinateur de son utilisateur. Elle publie une vidéo verticale sur la chaîne YouTube et le compte Instagram que l'utilisateur connecte lui-même, par les API officielles de ces plateformes, et prépare la publication sur TikTok, que l'utilisateur termine dans TikTok Studio. Un assistant facultatif propose un titre et des légendes, et un onglet affiche les statistiques des dernières vidéos publiées.

Vertipost n'a pas de serveur : les comptes connectés et les réglages restent sur l'ordinateur de l'utilisateur.

In English

Vertipost is a Windows desktop application that publishes a vertical video to YouTube Shorts and Instagram Reels through their official APIs, on the accounts the user connects, and prepares the TikTok post that the user completes in TikTok Studio. An optional assistant suggests a title and captions, and a tab shows the statistics of the latest videos. Vertipost has no server: connected accounts and settings stay on the user's computer.
