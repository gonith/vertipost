Règles de confidentialité

Dernière mise à jour : 27 octobre 2026 · English version below

Vertipost est une application de bureau pour Windows. Elle n'a pas de serveur : son éditeur ne reçoit, ne stocke et ne consulte aucune donnée de ses utilisateurs. Cette page décrit ce que l'application fait des données sur l'ordinateur où elle est installée.

Données auxquelles Vertipost accède

YouTube (services d'API YouTube de Google)

Quand l'utilisateur connecte sa chaîne, Vertipost demande l'autorisation de :

  • mettre en ligne les vidéos que l'utilisateur choisit de publier, avec le titre, la description et la catégorie qu'il a saisis ;
  • lire la liste de ses dernières vidéos et leurs statistiques (vues, mentions J'aime, commentaires) pour les afficher dans l'onglet Statistiques ;
  • modifier le titre d'une de ses vidéos, uniquement quand l'utilisateur clique sur « Renommer sur YouTube » ;
  • rechercher des vidéos publiques sur YouTube à partir des mots-clés que l'utilisateur a saisis.

Instagram (Meta)

Vertipost publie les Reels que l'utilisateur choisit sur le compte Instagram professionnel qu'il connecte, et lit les statistiques de ses dernières publications.

TikTok

Par défaut, Vertipost n'utilise pas l'API de TikTok : il ouvre la page d'envoi de TikTok Studio dans le navigateur et copie la légende dans le presse-papiers. Si l'utilisateur active un mode API, Vertipost envoie la vidéo choisie sur son compte TikTok.

Utilisation des données

Ces données servent uniquement aux fonctions que l'utilisateur déclenche lui-même dans l'application : publier, afficher ses statistiques, renommer une vidéo. Elles ne sont ni vendues, ni partagées avec des tiers, ni utilisées à des fins publicitaires.

L'utilisation et le transfert des informations reçues des API Google respectent les règles relatives aux données utilisateur des services d'API Google, y compris les exigences d'utilisation limitée.

Assistant (facultatif)

Si l'utilisateur active l'assistant et y enregistre sa propre clé, Vertipost envoie au fournisseur d'IA qu'il a choisi (Google Gemini ou Anthropic Claude) la description de la vidéo, les mots-clés saisis et, pour l'analyse, les titres et statistiques de ses dernières vidéos. Ces envois sont soumis aux règles de confidentialité de ce fournisseur. Sans clé, rien n'est envoyé.

Stockage et sécurité

Les jetons d'accès, identifiants et clés sont enregistrés sur l'ordinateur de l'utilisateur, dans le dossier %APPDATA%\vertipost, chiffrés par Windows (DPAPI). Ils ne transitent que vers les plateformes concernées, par des connexions chiffrées (HTTPS). Vertipost ne contient aucun outil de mesure d'audience ni de suivi.

Suppression et révocation

  • Le bouton « Déconnecter » de chaque plateforme supprime ses jetons de l'ordinateur.
  • Désinstaller Vertipost et supprimer le dossier %APPDATA%\vertipost efface toutes ses données.
  • L'accès à un compte Google peut être révoqué à tout moment sur la page Applications tierces de votre compte Google.
  • L'accès Instagram se révoque dans les paramètres Facebook, rubrique « Intégrations professionnelles ».

Règles des plateformes

En connectant YouTube, l'utilisateur accepte les Conditions d'utilisation de YouTube, et ses données sont aussi soumises aux Règles de confidentialité de Google.

Pour toute question : github.com/gonith/vertipost/issues.

Privacy Policy

Last updated: October 27, 2026

Vertipost is a Windows desktop application. It has no server: its publisher does not receive, store or access any user data. This page describes what the application does with data on the computer where it is installed.

Data Vertipost accesses

YouTube (YouTube API Services by Google)

When the user connects a channel, Vertipost asks for permission to:

  • upload the videos the user chooses to publish, with the title, description and category they entered;
  • read the list of their latest videos and their statistics (views, likes, comments) to show them in the Statistics tab;
  • change the title of one of their videos, only when the user clicks “Rename on YouTube”;
  • search public YouTube videos for keywords the user entered.

Instagram (Meta)

Vertipost publishes the Reels the user chooses to the professional Instagram account they connect, and reads the statistics of their latest posts.

TikTok

By default Vertipost does not use the TikTok API: it opens the TikTok Studio upload page in the browser and copies the caption to the clipboard. If the user enables an API mode, Vertipost uploads the chosen video to their TikTok account.

How data is used

This data is used only for the features the user triggers in the application: publishing, showing their statistics, renaming a video. It is not sold, shared with third parties or used for advertising.

Vertipost's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Assistant (optional)

If the user enables the assistant and saves their own key, Vertipost sends to the AI provider they chose (Google Gemini or Anthropic Claude) the video description, the keywords entered and, for the analysis, the titles and statistics of their latest videos. These requests are subject to that provider's privacy policy. Without a key, nothing is sent.

Storage and security

Access tokens, credentials and keys are stored on the user's computer, in the %APPDATA%\vertipost folder, encrypted by Windows (DPAPI). They are only sent to the platforms concerned, over encrypted connections (HTTPS). Vertipost contains no analytics or tracking.

Deletion and revocation

  • The “Disconnect” button of each platform deletes its tokens from the computer.
  • Uninstalling Vertipost and deleting the %APPDATA%\vertipost folder erases all its data.
  • Access to a Google account can be revoked at any time on the Google Account third-party apps page.
  • Instagram access is revoked in Facebook settings, under “Business integrations”.

Platform policies

By connecting YouTube, the user agrees to the YouTube Terms of Service, and their data is also subject to the Google Privacy Policy.
